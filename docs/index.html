Deploy Your Own Live Instance

Run locally or host it free on the cloud with Docker.

1

1-Click Deploy on Render.com (Recommended)

Click the button below to deploy this repository directly to Render. It automatically builds FFmpeg and runs the app on a free HTTPS URL.

2

Run Locally on Windows

Clone the repository and double-click run.bat:

git clone https://github.com/pureeye108/photo-map-explorer.git
cd photo-map-explorer
run.bat
3

Run with Docker

docker build -t photo-map-explorer .
docker run -p 5000:7860 photo-map-explorer
